Operators are the core vocabulary of expression evaluation in Rust. They are defined for built-in types directly by the language, and many can be overloaded for custom types using traits in `std::ops` or `std::cmp`. This page covers every operator expression in Rust, from simple arithmetic to the error propagation operator.

## Overflow

Integer operators panic when they overflow in debug mode (controlled by `-C debug-assertions` and `-C overflow-checks`). The following are considered overflow:

- `+`, `*`, or binary `-` producing a value outside the type's representable range.
- Applying unary `-` to the most negative value of a signed integer type (unless the operand is a literal expression or a grouped literal expression).
- Using `/` or `%` where the left-hand argument is the smallest signed integer value and the right-hand argument is `-1`.
- Using `<<` or `>>` where the right-hand argument is ≥ the number of bits in the type, or is negative.

<Note>
  Forms such as `-128_i8` or `let j: i8 = -(128)` never cause a panic and always produce the expected value of -128, because the literal `128_i8` already has the value -128 via two's complement truncation.
</Note>

## Borrow Operators

```
& Expression
&mut Expression
& raw const Expression
& raw mut Expression
```

The `&` (shared borrow) and `&mut` (mutable borrow) operators are unary prefix operators.

- Applied to a **place expression**, they produce a reference to the memory location.
- Applied to a **value expression**, they create a temporary value and produce a reference to it.
- For a shared borrow (`&`), the place may not be mutated but may be read or shared again.
- For a mutable borrow (`&mut`), the place may not be accessed in any way until the borrow expires.

```rust
{
    // a temporary with value 7 is created that lasts for this scope
    let shared_reference = &7;
}
let mut array = [-2, 3, 9];
{
    // mutably borrows `array` for this scope
    let mutable_reference = &mut array;
}
```

Even though `&&` is a single token (the lazy 'and' operator), in borrow expressions it acts as two borrows:

```rust
let a = &&  10;     // same as: & & 10
let a = &&&& mut 10; // same as: & & & & mut 10
```

### Raw Borrow Operators

`&raw const` and `&raw mut` create raw pointers (`*const T` and `*mut T` respectively). They must be used instead of normal borrows when the place expression may not be properly aligned, may not store a valid value, or when creating a reference would introduce incorrect aliasing assumptions.

```rust
#[repr(packed)]
struct Packed {
    f1: u8,
    f2: u16,
}

let packed = Packed { f1: 1, f2: 2 };
// `&packed.f2` would be undefined behavior — unaligned reference!
let raw_f2 = &raw const packed.f2;
assert_eq!(unsafe { raw_f2.read_unaligned() }, 2);
```

## The Dereference Operator

```
* Expression
```

The `*` (dereference) operator is a unary prefix operator. Applied to a pointer or `Box`, it denotes the pointed-to location.

- If the expression type is `&mut T`, `*mut T`, or `Box<T>` and is a mutable place expression, the resulting memory location can be assigned to.
- Dereferencing a raw pointer requires `unsafe`.
- On non-pointer types, `*x` is equivalent to `*std::ops::Deref::deref(&x)` (or `DerefMut` in a mutable context).

```rust
let a = &7;
assert_eq!(*a, 7);
let b = &mut 9;
*b = 11;
assert_eq!(*b, 11);
```

## The Try (Error Propagation) Operator

```
Expression ?
```

The try propagation expression (`?`) uses the [`Try`] trait to decide whether to produce a value or return early from the function. It is most commonly used with `Result` and `Option`.

```rust
use std::num::ParseIntError;

fn try_to_parse() -> Result<i32, ParseIntError> {
    let x: i32 = "123".parse()?; // x is 123
    let y: i32 = "24a".parse()?; // Returns an Err() immediately
    Ok(x + y)                    // doesn't run
}

let res = try_to_parse();
println!("{res:?}");
```

```rust
fn try_option_some() -> Option<u8> {
    let val = Some(1)?;
    Some(val)
}
assert_eq!(try_option_some(), Some(1));

fn try_option_none() -> Option<u8> {
    let val = None?;
    Some(val)
}
assert_eq!(try_option_none(), None);
```

The `?` operator can be applied to:
- `Result<T, E>`: `Ok(val)` → `val`; `Err(e)` → returns `Err(From::from(e))`
- `Option<T>`: `Some(val)` → `val`; `None` → returns `None`
- `ControlFlow<B, C>`: `Continue(c)` → `c`; `Break(b)` → returns `Break(b)`

<Note>
  The `?` operator is sometimes called the *question mark operator*, the *try operator*, or the *error propagation operator*.
</Note>

## Negation Operators

```
- Expression
! Expression
```

| Symbol | Integer | `bool` | Floating Point | Overloading Trait |
|--------|---------|--------|----------------|-------------------|
| `-` | Negation (signed only) | | Negation | `std::ops::Neg` |
| `!` | Bitwise NOT | Logical NOT | | `std::ops::Not` |

```rust
let x = 6;
assert_eq!(-x, -6);
assert_eq!(!x, -7);
assert_eq!(true, !false);
```

## Arithmetic and Logical Binary Operators

Binary operator expressions are written with infix notation. Operands are evaluated in value expression context (moved or copied).

| Symbol | Integer | `bool` | Float | Overloading Trait | Compound Assign Trait |
|--------|---------|--------|-------|-------------------|-----------------------|
| `+` | Addition | | Addition | `std::ops::Add` | `std::ops::AddAssign` |
| `-` | Subtraction | | Subtraction | `std::ops::Sub` | `std::ops::SubAssign` |
| `*` | Multiplication | | Multiplication | `std::ops::Mul` | `std::ops::MulAssign` |
| `/` | Division† | | Division | `std::ops::Div` | `std::ops::DivAssign` |
| `%` | Remainder†‡ | | Remainder | `std::ops::Rem` | `std::ops::RemAssign` |
| `&` | Bitwise AND | Logical AND | | `std::ops::BitAnd` | `std::ops::BitAndAssign` |
| `\|` | Bitwise OR | Logical OR | | `std::ops::BitOr` | `std::ops::BitOrAssign` |
| `^` | Bitwise XOR | Logical XOR | | `std::ops::BitXor` | `std::ops::BitXorAssign` |
| `<<` | Left Shift | | | `std::ops::Shl` | `std::ops::ShlAssign` |
| `>>` | Right Shift§ | | | `std::ops::Shr` | `std::ops::ShrAssign` |

† Integer division rounds towards zero. Division by zero panics.  
‡ Remainder has the same sign as the dividend (truncating division).  
§ Arithmetic right shift on signed integers; logical right shift on unsigned.

```rust
assert_eq!(3 + 6, 9);
assert_eq!(5.5 - 1.25, 4.25);
assert_eq!(-5 * 14, -70);
assert_eq!(14 / 3, 4);
assert_eq!(100 % 7, 2);
assert_eq!(0b1010 & 0b1100, 0b1000);
assert_eq!(0b1010 | 0b1100, 0b1110);
assert_eq!(0b1010 ^ 0b1100, 0b110);
assert_eq!(13 << 3, 104);
assert_eq!(-10 >> 2, -3);
```

## Comparison Operators

Comparison operators are defined for primitive types and many standard library types. Parentheses are required when chaining comparisons — `a == b == c` is invalid; write `(a == b) == c` instead.

Unlike arithmetic operators, comparison operators **implicitly take shared borrows** of their operands:

```rust
let a = 1;
let b = 1;
a == b;
// equivalent to:
::std::cmp::PartialEq::eq(&a, &b);
```

| Symbol | Meaning | Overloading Method |
|--------|---------|--------------------|
| `==` | Equal | `std::cmp::PartialEq::eq` |
| `!=` | Not equal | `std::cmp::PartialEq::ne` |
| `>` | Greater than | `std::cmp::PartialOrd::gt` |
| `<` | Less than | `std::cmp::PartialOrd::lt` |
| `>=` | Greater than or equal to | `std::cmp::PartialOrd::ge` |
| `<=` | Less than or equal to | `std::cmp::PartialOrd::le` |

```rust
assert!(123 == 123);
assert!(23 != -12);
assert!(12.5 > 12.2);
assert!([1, 2, 3] < [1, 3, 4]);
assert!('A' <= 'B');
assert!("World" >= "Hello");
```

## Lazy Boolean Operators

```
Expression && Expression
Expression || Expression
```

`&&` denotes logical 'and' and `||` denotes logical 'or' for boolean operands. Unlike `&` and `|`, the right-hand operand is only evaluated when necessary:

- `||` only evaluates its right-hand operand when the left-hand operand is `false`.
- `&&` only evaluates its right-hand operand when the left-hand operand is `true`.

```rust
let x = false || true;        // true
let y = false && panic!();    // false, doesn't evaluate `panic!()`
```

## Type Cast Expressions (`as`)

```
Expression as TypeNoBounds
```

An `as` expression explicitly casts a value from one type to another. It can perform coercions and additional casts including:

- **Numeric cast** — between integer and float types
- **Enum cast** — enum to its discriminant integer
- **Primitive to integer** — `bool` or `char` to integer
- **`u8` to `char`** cast
- **Pointer casts** — between raw pointer types
- **Function item/pointer to integer or pointer**
- **Closure to function pointer** (non-capturing closures only)

```rust
fn average(values: &[f64]) -> f64 {
    let sum: f64 = values.iter().sum();
    let size: f64 = values.len() as f64;
    sum / size
}
```

**Numeric cast semantics:**

```rust
// Same-size integer cast (no-op in representation):
assert_eq!(42i8 as u8, 42u8);
assert_eq!(-1i8 as u8, 255u8);

// Truncation (larger to smaller):
assert_eq!(1234u16 as u8, 210u8);

// Extension (smaller to larger):
assert_eq!(-17i8 as i16, -17i16); // sign-extended

// Float to integer (rounds toward zero, saturates at boundaries):
assert_eq!(42.9f32 as i32, 42);
assert_eq!(std::f32::NAN as i32, 0);
assert_eq!(1_000_000_000_000_000f32 as i32, 0x7fffffff);

// Integer to float:
assert_eq!(1337i32 as f32, 1337f32);

// bool and char to integer:
assert_eq!(false as i32, 0);
assert_eq!(true as i32, 1);
assert_eq!('A' as i32, 65);

// u8 to char:
assert_eq!(65u8 as char, 'A');
```

<Warning>
  Casting from an integer to a raw pointer (`integer as *mut T`) interprets the integer as a memory address. Dereferencing such a pointer may be undefined behavior if aliasing rules are not followed.
</Warning>

## Assignment Expressions

```
Expression = Expression
```

An assignment expression moves a value into a specified place. The assigned value operand (right side) is evaluated **first**, then the assignee expression (left side).

An assignment expression always produces the unit value `()`.

```rust
let mut x = 0;
let y = 0;
x = y;
```

### Destructuring Assignment

Assignment also supports destructuring, mirroring destructuring `let` bindings:

```rust
let (mut a, mut b) = (0, 1);
// swap a and b:
(b, a) = (a, b);
```

```rust
let mut a = 0;
let mut b = 0;
(a, b) = (3, 4);
[a, b] = [3, 4];
```

Underscore expressions and empty range expressions may be used to discard certain values without binding them:

```rust
let p = (1, 2);
let mut a = 0;
(_, a) = p;
_ = 2 + 2; // explicitly ignore result
```

## Compound Assignment Expressions

```
Expression += Expression
Expression -= Expression
Expression *= Expression
// ...and so on for -=, *=, /=, %=, &=, |=, ^=, <<=, >>=
```

*Compound assignment expressions* combine arithmetic/logical binary operators with assignment. They always produce the unit value `()`.

```rust
let mut x = 5;
x += 1;
assert!(x == 6);
```

<Warning>
  When both operands are primitive types known before monomorphization, the right-hand side is evaluated **before** the left-hand side — opposite to the usual left-to-right order. For non-primitive types the left-hand side is evaluated first. Avoid writing code that relies on this evaluation order.
</Warning>

For non-primitive types, compound assignment is syntactic sugar for calling the corresponding trait method (e.g., `x += y` desugars to `x.add_assign(y)`).
