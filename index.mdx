The Rust Reference is the authoritative specification for the Rust programming language. It documents every language construct — from lexical tokens and items to the type system, memory model, and unsafe operations — with precision aimed at developers who need to understand exactly how Rust works, not just how to use it.

<Note>
  This reference assumes background familiarity with Rust. If you're new to the language, start with [The Rust Book](https://doc.rust-lang.org/book/) first. For the standard library API, see [docs.rust-lang.org](https://doc.rust-lang.org/std/).
</Note>

## How to Use This Reference

<Steps>
  <Step title="Look up a specific construct">
    Use the sidebar to navigate directly to the section covering the language feature you need. Each chapter can be read standalone.
  </Step>
  <Step title="Follow cross-references">
    Pages link to related concepts across the reference. When a topic references another, follow the link for the full specification.
  </Step>
  <Step title="Check the Appendices">
    The [Glossary](/appendices/glossary) defines key terms, the [Syntax Index](/appendices/syntax-index) lists every grammar production, and the [Influences](/appendices/influences) page explains design decisions.
  </Step>
</Steps>

<Tip>
  The reference covers only **stable** Rust. For unstable features, see the [Unstable Book](https://doc.rust-lang.org/unstable-book/). For `rustc`-specific flags, see the [rustc Book](https://doc.rust-lang.org/rustc/). For Cargo, see the [Cargo Book](https://doc.rust-lang.org/cargo/).
</Tip>
